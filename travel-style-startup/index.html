01｜执行摘要：先做生意，再做平台

核心判断：这是一个场景明确的消费决策问题，但“生成好看的AI搭配图”不足以建立商业壁垒。真正需要打通的是：场景理解 → 个人适配 → 真实SKU → 及时交付 → 出片反馈。

大理 / 洱海

早期形态
内容 + 人工辅助AI

小红书获客、表单收需求、人工匹配真实商品

商业目标
成交和贡献利润

优先验证净佣金及用户体验，而非下载量和GMV

战略优先级：内容商业验证 → 标准化服务 → 轻量H5/小程序 → 交易数据沉淀 → 自有供应链。不建议第一阶段投入完整App、自营仓和大规模库存。

03｜目标用户与价值主张

第一阶段核心客群

23–35岁，已确定行程的旅行女性

拍照需求明确、临近出行、愿意花时间研究穿搭，对“穿错不出片”敏感；年龄仅为测试起点，非验证后结论。

触发节点：订好机酒 / 整理行李 / 搜索“洱海穿什么”。

用户雇佣产品完成的任务

让我带得少、买得准、拍得好

按每个拍照点获取风格建议，兼顾体型、气温、步行和预算，并在出发前得到真正能买到的衣服。

信任关键：真实商品、尺码建议、库存、实拍与退换机制。

三类推荐并存

最出片

注重颜色反差、人物轮廓和场景氛围

最实穿

注重活动便利、气候和复穿率

最省钱

优先利用衣橱，仅补充必要单品

04｜MVP：先提供方案和购买，不开发重系统

01

内容入口

小红书景点穿搭笔记：景点、季节、预算、照片示例、避坑

02

需求表单

城市、日期、预算、风格、尺码偏好、已有单品（自愿）

03

方案交付

AI生成草稿 + 人工校验，交付三选一搭配和行李清单

04

商品成交

真实SKU、替代款、交期、合规成交路径、售后反馈

一次完整订单的体验

内容种草 → 申请穿搭 → 收到3套建议 → 选择1套 → 进入商品页 → 签收和实拍反馈。AI只解决决策的一部分，商品链接和服务承诺必须可核实。

第一版不必开发虚拟试衣。AI试穿可能增强传播，但对实际面料、尺码和合身程度存在误导风险。优先建设景点规则库与高质量商品库。

05｜商业模式：四条收入线，分阶段开启

收入方式客户付费点何时开展主要风险
联盟/商家分佣服饰真实成交后按规则结算第1阶段退货、佣金取消、平台规则
付费深度方案多日搭配、衣橱复用、专业复核第2阶段，小样本测试9.9–39.9元服务成本大于收费
精选穿搭套装多件推荐/搭配组合复购和选品数据出现后库存、尺码、售后
品牌营销合作商家专题、内容合作稳定流量后破坏推荐客观性

推荐收入结构：先按效果收佣金，附加小规模服务费试验。没有稳定成交数据之前不对外承诺付费平台规模或融资故事。

08｜采购与履约：不能停在好看的图上

选品池

首批30–50个SKU：连衣裙、开衫、平底鞋、帽子、包袋与配饰。优先款式稳定且复穿性好。

商家筛选

获取材质、尺码表、实拍、发货地、库存更新、退换货和结算规则。测试样衣不可省。

交付判断

按旅行出发日期倒排发货时效；建立缺货替代SKU，遇到不可保障交期的商品直接不推荐。

单品信息结构（建议数据库字段）

SKU ID / 分类 / 图片授权 / 适用场景 / 主色 / 面料 / 季节 / 尺码与版型 / 商品价格 / 佣金与结算条件 / 库存更新时间 / 发货时效 / 退货表现 / 推荐理由 / 替代SKU。

用户信任是一种商业资产。应明确标注佣金合作，推荐顺序优先考虑适配与交付，不能因某款分佣更高就隐瞒其尺码和时效风险。

09｜90天执行路线图

1–14天

需求发现

聚焦大理；访谈20–30人，发布15–20条内容，试制10个有SKU的搭配方案。

可否吸引申请？
15–30天

人工成交

表单+AI辅助+人工审核，逐一记录点击、付费与用户疑问。

有人真买吗？
31–45天

复盘优化

淘汰低质量货盘；试验深度穿搭服务，确认退款后利润。

单笔是否为正？
46–90天

轻量复制

搭建H5/小程序最低功能版，扩展第二目的地，检验内容与SKU复用。

能复制吗？

阶段性交付物

阶段应产出文件或数据停止/继续依据
第14天访谈表、内容数据、景点规则卡、10套实物清单是否有高意向用户主动申请
第45天真实订单台账、退款台账、前50条有效咨询语料是否有可复现的订单和满意交付
第90天第二目的地复用报告、模型需求文档、单位经济报告是否值得技术和供应链追加投入

10｜北极星指标、阶段目标与Go/No-Go

北极星建议：每100名有效穿搭申请用户带来的“退款后订单贡献”，同时观察满意度；不要用总GMV代替利润。

指标90天建议验证线说明
有效方案申请累计 ≥100明确日期/目的地/预算的用户
初始成交用户10–15人记录最终结算与退款
深度方案付费≥5笔观察服务交付工时
满意反馈≥80%正向明确样本量和回访口径
单笔订单贡献≥0元扣除可变服务与获客支出
第二目的地复制完成1个流程和选品系统可复用

以上都是创业筛选门槛，不是行业基准。样本量小，宜以趋势和访谈事实辅助判断。

Go：可以追加投入

有稳定付费/成交来源；退款后单笔贡献为正；内容到订单链路可追踪；至少部分SKU适合复用。

No-Go / Pivot：需要调整

只收藏不申请：调整需求与流量定位；只申请不购买：提高商品适配；有订单却亏损：调整货盘、定价和获客；满意度低：暂停扩张。

11｜风险、伦理与合规边界

风险早期策略
推荐同质化积累景点拍照位、季节、真实SKU和售后效果数据
广告与商业合作透明度披露商业合作关系，避免伪装个人客观推荐
照片与身体数据隐私最小化收集、明确用途、有限保存与删除机制
虚拟试穿误导明确标识模拟图，真实商品展示不以生成图代替
图像版权和肖像权取得照片授权，不随意搬运摄影师与旅游博主素材
安全与天气拍照建议不得优先于徒步、交通、气温与防晒安全
跨平台交易确认推广、跳转、分佣与支付遵守平台规则和经营要求

关于隐私、广告、电子商务与生成式AI图片标识的法律义务，应在正式上线时根据实际产品形式和经营主体向专业人士核查。
