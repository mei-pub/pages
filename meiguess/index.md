# 美猜

「你说我猜」桌游 App。一台手机开局：描述者看词，其他人喊答案，App 实时判定。

- 按住说话、松手即判定，零延迟反馈
- 猜错给方向引导，也可切「问一问」用是非题排除范围
- AI 出题 / 智能判定 / 问一问 / 方向引导**已包含在买断里**，不额外收费
  （需自行填写 API Key，支持 OpenAI / Anthropic / 智谱 / DeepSeek / MiniMax / Kimi）
- 可选买断「本地 AI 推理」扩展：模型装在自己手机里跑，完全离线
- 不填 Key 也能完整玩：内置 120 词词库 + 本地判定
- 自动排除玩过的词，可按分类切换；战绩与历史分离
- 浅色 / 深色主题
